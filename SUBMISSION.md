# Сдача тестового задания Ecomdev

Репозиторий: **https://github.com/sty-alt/ecomdev-payments**

Реализованы части 1–3. Для интерфейса выбран вариант Б: мобильная веб-страница со списком должников и формой оплаты. Telegram-бот — дополнительный вариант А.

## Часть 4 — использование ИИ (8 предложений)

Для выполнения задания использовались Claude Code и Codex, и я не выдаю сгенерированный ими код за написанный вручную.
Claude Code использовался на этапе первоначальной разработки: API учеников и оплат, SQLite, расчёт должников, веб-интерфейс, Telegram-бот, базовые тесты и README.
Codex затем провёл проверку по ТЗ, исправил найденные ошибки, расширил тесты и подготовил проект к публикации на GitHub.
Наиболее полезным форматом запроса оказалось полное ТЗ вместе с конкретной задачей «проверь всё, чтобы работало и соответствовало ТЗ», после которой агент должен был подтвердить результат командами и проверкой интерфейса в браузере.
При проверке обнаружились ошибки типов в тестовом помощнике, ссылка без доступного названия, различающиеся часовые пояса сервера и браузера, а также ответ 500 при внесении суммы меньше копейки.
Эти проблемы были найдены через TypeScript, Biome, чтение кода и дополнительный тест, воспроизводящий ошибку, после чего Codex внёс исправления и повторил проверки.
Итоговая проверка включает 92 автоматических теста, сборку, проверку типов, линтер, чистую установку зависимостей, сохранение данных после повторного открытия БД и основные действия пользователя в мобильном браузере.
Мой вклад — передача ТЗ агентам, постановка задач на доработку и согласование результата; ручное написание программного кода в этой версии я не заявляю.

## Проверенные ограничения

- Все обязательные функции выбранного веб-варианта реализованы и проверены локально.
- Telegram-команды проверены автоматическими тестами; запуск с настоящим токеном не проверен.
- Dockerfile и Compose добавлены; сборка Docker-образа не проверена, поскольку Docker отсутствует в среде разработки.
- История тарифов не хранится: изменение месячной суммы меняет расчёт прошлых месяцев.
- Оплата учитывается в месяце своей даты; переплата между месяцами не переносится.
